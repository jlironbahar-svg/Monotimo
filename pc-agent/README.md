# Desktop Friend: PC agent

The PC side of [Desktop Friend](../README.md): a local WebSocket server with QR pairing, the AI's transparent
blue-cursor overlay, screen vision, mouse/keyboard automation and the Groq + ElevenLabs brain.

```bash
./start.sh               # macOS / Linux  (Windows: start.bat)
python -m desktop_friend --help
```

See the [main README](../README.md#1-run-the-pc-agent) for setup, configuration and OS permissions.
